## 一、项目概述

**目标**:在 GTDB(Genome Taxonomy Database)R232 全基因组集合(199,923 个代表基因组,含细菌+古菌)中,系统鉴定 PHB(聚羟基丁酸酯)降解相关基因,并做生态/分类学分布与系统发育分析。

**方法范式**:文献调研 → 种子收集 → 分家族 HMM → 全库蛋白预测 → HMM 筛选 → 功能验证 → 三级重评分 → 系统发育 → 生态分布 → 基因簇共定位(参考 Zrimec 2021 mBio、Viljakainen & Hug 2021)。

**当前阶段**:主体分析已完成,tier1 结果与生态/基因簇分析已产出;处于"投稿前修正与完善"阶段。

### 5.3 古菌 patatin(经基因簇复筛)

- 古菌 patatin 折叠蛋白:tier1 1,372 条 / 620 基因组;
- **±10kb 基因簇复筛**:仅 **340 条(24.8%)** 邻近 PHB 代谢基因(BdhA 274、PhaC 63、PhaE 56、PhaJ 11);其余 75.2% 无 PHB 上下文 = 广谱磷脂酶背景;
- **判据依据**:PhaZh1 与 bdhA 成簇(Liu 2015,PMID 25710370)。

### 5.4 古菌 patatin 结论(审慎表述)

古菌 PHB 降解基因**确实存在**(核心解聚酶在 Halobacteriota 112 + Thermoproteota 32 + Thermoplasmatota 154 基因组);但 **patatin 型"解聚酶"应审慎表述**:
1. patatin 是广谱磷脂酶结构域,75.2% 命中无 PHB 上下文;
2. PhaZh1 型体内角色有限(敲除不影响动员);
3. **PhaJ(烯酰-CoA 水合酶)才是古菌动员主通路**。
