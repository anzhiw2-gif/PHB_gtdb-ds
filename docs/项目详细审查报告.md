## 1. 项目概述与科学问题

**科学问题**：PHB（聚-3-羟基丁酸酯）是细菌最广泛合成的胞内储能聚合物，也是
生物可降解塑料的典型代表。其**降解**（解聚）是塑料生物循环的关键环节，但
"哪些微生物谱系拥有 PHB 降解基因、这些基因如何分布与演化"在**全基因组尺度**
尚未系统回答。

**本研究目标**：在 GTDB（Genome Taxonomy Database）R232 全基因组集合（199,923 个
代表基因组，含细菌 + 古菌）中，系统鉴定 PHB 降解相关基因，并完成：

- 高质量 PHB 降解基因参考序列集 + 分家族 HMM profile；
- 全库筛选 → 功能验证 → 三级重评分（tier1/2/3）；
- 生态/分类学分布统计；
- 系统发育分析；
- 古菌 PHB 降解基因的专门考察。

**方法范式**：文献调研 → 种子收集 → 分家族 HMM → 全库蛋白预测 → HMM 筛选 →
功能验证 → 三级重评分 → 系统发育 → 生态分布 → 基因簇共定位。
（参考 Zrimec 2021 mBio；Viljakainen & Hug 2021 Environ Microbiol。）

**新颖性**：已有宏基因组规模工作（V&H 2021，3,078 宏基因组中 13,869 个推定 PHA
解聚酶），但**无基于 GTDB 统一分类框架的全库先例**；古菌 PHB 降解基因此前仅
*Haloferax mediterranei* 的 PhaZh1（PMID 25710370）被实验表征。

## 3. 完整方法流程

### 3.1 家族分类体系（9 个 HMM 家族）

分类口径唯一来源：`knowledge/family_classification.md` §6.4。

| 类型 | 家族 | 功能 | EC / 依据 | 计入核心解聚酶 |
|------|------|------|----------|:---:|
| 核心解聚酶 | **ePhaZ** | 胞外 PHB/PHA 解聚酶 | EC 3.1.1.75/76；PhaDED 家族 5+6+8 | ✅ |
| 核心解聚酶 | **iPhaZ** | 胞内 PHA 解聚酶（Cys/Ser/周质型） | PhaDED 家族 1+2+3+4 | ✅ |
| 核心解聚酶 | **OH** | 3HB 寡聚体水解酶 | EC 3.1.1.22 / PhaY | ✅ |
| 核心解聚酶 | **ArchPhaZ_hydrolase** | 古菌经典 PHB 解聚酶家族酯酶 | 12 条 Halobacteria 种子 | ✅ |
| 广谱折叠 | ArchPhaZ_patatin | 古菌 patatin 折叠（PhaZh1 型候选） | Pfam Patatin（PF01734） | ⚠️ 需基因簇过滤 |
| 背景代谢 | BdhA | 3HB 脱氢酶 | EC 1.1.1.30 | ❌ |
| 辅助 | PhaJ / phasin / PhaC | 动员（MaoC/PF01575）/ 颗粒（PF09361）/ 合酶（K03821） | 簇背景 | ❌ |

**催化位点规则**：α/β-水解酶折叠，催化三联体 **Ser/Cys-Asp/Glu-His**（酸性残基
Asp 与 Glu 可互换，例证 *Thermus thermophilus* HB8 的 Ser183-Glu310-His405，
PMID 19214501）；催化 Ser 位于 Gx₁Sx₂G lipase box，x₁ 几乎全为疏水残基。

### 3.2 管线步骤（01–11）

| 步骤 | 脚本 | 原理 |
|------|------|------|
| 01 种子收集 | `02_collect_seeds.py` + `02b–02e` | UniProt + PAZy + ESTHER 多源 |
| 02 分家族 | `03_prep_families.py` | 标签 → 家族映射 |
| 03 HMM 构建 | `04b_build_hmms_v2.sh` | CD-HIT c90 → MAFFT → hmmbuild |
| 04 蛋白预测 | `05_predict_proteins.sh` | Pyrodigal meta |
| 04b 过滤 | `06a_filter_shards.sh` | 剔除 >100K aa 伪影 |
| 05 全库筛选 | `06_screen.sh` + `06b_aggregate_hits.py` | HMMER E<1e-5 + cov 列 |
| 06 命中处理 | `07_process_hits.py` + `07b_extract_seqs.py` | E/cov 过滤、仲裁、去重、提取 |
| 07 功能验证 | `08_validate.py` | lipase box + 三联体 + 长度 |
| 08 三级重评分 | `08c_tier_rescore.py` | curated HMM E<1e-20（tier1）/ 1e-10（tier2） |
| 09 系统发育 | `09b_tier1_phylogeny.sh` / `09g_fasttree.sh` | MAFFT → trimAl → IQ-TREE2 / FastTree |
| 10 生态分布 | `10_distribution.py` | 分类学 + isolation source |
| 11 基因簇 | `11_clusters.py` | ±10kb 邻域共定位 |

### 3.3 三级重评分（tier 定义）

- **tier1**：curated 金标准 HMM 重评分 **E < 1e-20**（严格，主交付物）；
- **tier2**：curated HMM **E < 1e-10**（中等）；
- **tier3**：宽模型 + 通用验证（`*_validated.faa`）。

### 3.4 覆盖度（min-cov）校准与家族差异化阈值

`06b_aggregate_hits.py` 从 domtblout 计算每命中的 HMM 覆盖度
（max domain `(hmm_to−hmm_from+1)/qlen`），写入 `hits_all.tsv` 的 `cov` 列。
`07_process_hits.py` 支持 `--family-min-cov` 按家族差异化阈值：
**OH 家族 `--min-cov 0.6`（排除尼龙水解酶），ePhaZ/iPhaZ 维持 min-cov 0**（校准结论，见 §5.4）。

### 4.3 古菌 patatin（历史邻域记录，待新 schema 复核）

- **讨论子集**：古菌 patatin 折叠蛋白 tier1 **1,372 位点 / 620 基因组**；广谱 patatin 候选蛋白记录层另有 **112,926** 条，二者不是同一统计单位。
- Figure 5 的 `results/figures/scheme_a/source_data/figure5_neighborhood_rate.tsv` 使用**全命中邻域层**的
  `candidate_loci` 作 denominator；patatin 行为 315,065 个 candidate loci，而不是上述 1,372 个 tier1
  loci / 620 个 genome。历史叙述的 24.8% 不能直接回写为 patatin 子集比例；新 schema 虽区分出现次数、
  唯一位点和唯一基因组，仍需在明确层级的输入上单独汇总。
- **生物学 caveat**：patatin 是广谱磷脂酶结构域；PhaZh1 型体内角色有限
  （敲除不影响动员）；**PhaJ（烯酰-CoA 水合酶）才是古菌动员主通路**。
- 判据依据：PhaZh1 与 bdhA 成簇（Liu 2015，PMID 25710370）。

本研究产出是**基于 HMM 同源性 + 基序 + 邻域证据的候选同源蛋白**，未经酶活/遗传/表型
