## 二、我读出来的项目论证链（这才是要画的）

**问题**：在 GTDB R232 全库里找 PHB/PHA 解聚酶候选（PhaDED 架构：8 超家族 / 38 家族，Knoll 2009 定义）

**做法**：蛋白预测 → 10 模型全库扫描（E ≤ 1e-5）→ 候选构建（109,087）→ 多证据 fail-closed 筛选 → 高可信度 40,690 / 30,623 基因组

**六条关键诚实结论**（每条都有冻结数字）：

1. **支撑强度分层严重（最核心）** —— 40,690 条按 profile 证据分三层（实测复算，`merged_high_confidence_candidates.tsv`）：

   | 支撑证据 | 条数 | 占比 | 说明 |
   |---|---:|---:|---|
   | `profile_trained_hit`（trained profile） | **5,172** | 12.7% | 仅 type1（4,874）+ type2（298） |
   | `profile_ambiguous_family`（家族归属歧义） | **2,905** | 7.1% | nPHAMCL 987 全部、type2 1,812、dPHAMCL 96、type1 10 |
   | `discovery_hit`（**仅发现层 HMM**） | **32,613** | 80.1% | Cys 型 29,974 全部 + 池外 4,131 全部 + 其余 |

   → Cys 型（30,026 条，占 73.7%）的通过理由 = 发现层命中 + PF06850 检出 + 无 GxSxG + 无分泌信号；
     **没有任何 calibrated/trained profile 支撑**，且 `catalytic_residue_verification = inferred_cys_not_verified`（100%）。

2. **校准只走到一个家族** —— 六腿 gate 仅 **hfam_70（type2）全过**（`calibrated_candidate_model`），hfam_52 次选（含 2 条弱阳性），hfam_55/hfam_8 差 1 条阳性，**hfam_4（nPHAMCL）多腿失败**（challenge 3 个假阳性、held-out leakage 0.901）→ 已决定不再改 HMM，nPHAMCL 改走结构证据。（`T141_20260920_phaded_three_gaps_status.md` §④）

3. **"30 条实验阳性"的独立性被证伪** —— 溯源后只有 hfam_52、hfam_70 真正满足"≥3 条独立一手实验阳性"；**hfam_4 的训练集实为"1 条真阳性 + 2 条同一 *P. putida* 基因的纯序列重复"** → 该 profile 已从 trained 降级。（同上 §②）

4. **一次"差点误杀"的更正（正向亮点）** —— PF06850 不是胞外 SBD，而是**胞内 Cys 型的 C 端标记**；type-1"缺 SBD"是**用错标记**（coverage_artifact），5,018 条 100% 有正确的催化域标记 PF10503 → **不降级**。（同上 §③）

5. **定位从"未测"升级为"预测确认"** —— 29,521 条 Cys/nPHAMCL 候选补测 SignalP：**99.82% 确认胞内**（OTHER），仅 **52 条（0.18%）** 疑似分泌 → 已 demote，36,611→36,559，总计 40,742→**40,690**。（同上 §①）

6. **结构性断点仍在** —— 候选与 38 个冻结 DED 比对**零重叠**（`candidate_ded_alignment_members = 0`），因此 His/Asp 的逐条催化残基坐标**不可传递**，可判定率仅 **6.7% / 1.2%**；且台账 723 行里**实验阴性 0 条**（693 annotation_only + 30 positive）——族级阴性无法从现有证据构造。
